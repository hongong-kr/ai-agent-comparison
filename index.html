Codex vs Claude Code — 개발자용 코딩 에이전트

둘 다 생활 비서가 아니라 코드를 짜는 개발자용 도구예요. 쉽게 가입해 쓰는 비서들과 달리, 터미널·개발 환경에 붙여 쓰는 「개발자용」 갈래입니다. 결은 비슷해 보여도 일하는 자리가 정반대예요.
